# Spotify Clone 🎵

A frontend UI clone inspired by the Spotify web interface, created using **HTML, CSS, and Tailwind CSS**.

## 📌 About the Project

This project recreates the basic look and layout of the Spotify website as a frontend practice project. It focuses on responsive design, page structure, styling, and user interface development.

## ✨ Features

* Spotify-inspired user interface
* Responsive layout
* Sidebar navigation
* Music/playlist sections
* Modern card-based design
* Tailwind CSS styling

## 🛠️ Technologies Used

* HTML5
* CSS3
* Tailwind CSS

## 🚀 How to Run

1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.

## 🎯 Purpose

This project was created to practice **HTML, CSS, Tailwind CSS, and responsive frontend design**.

> **Note:** This is a frontend UI clone created for educational and practice purposes. It is not affiliated with or endorsed by Spotify.
